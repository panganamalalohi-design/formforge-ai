# FormForge AI 🏭

### Explore the past. Discover better solutions. Design the future.

FormForge AI is an interactive product research and redesign workspace that helps designers explore product evolution, understand design decisions, identify limitations, and develop new product concepts.

Instead of treating product research and redesign as separate activities, FormForge AI connects them in one workflow.

**Live Demo:** https://formforge-oza0gk95i-panganamala-lohitha.vercel.app

## ✨ Features

### 🏠 Product Dashboard

* Explore products such as water bottles, chairs, lamps, and bicycles.
* Navigate the product research and redesign workspace.

### 📚 Product Research

* Explore product design concepts and research information.
* Organize product information for easier reference.

### 🕒 Evolution Timeline

* Explore sample entries about the evolution of water bottle designs.
* Understand design decisions, materials, problems addressed, and limitations.
* Connect historical design changes with product improvement opportunities.

### 💡 Design Solution Explorer

* Explore design problems and possible solutions.
* Ask questions about selected timeline entries.
* Use Demo Mode to explore example responses.

### 🎨 Redesign Studio

* Enter design requirements, preferred materials, and colours.
* Generate a structured concept brief using the available demo functionality.
* Organize redesign ideas into a clear concept.

### 💾 Saved Research

* Save research items for future reference.
* Access saved items through the application.

## 🚀 Getting Started

### Prerequisites

Install the following:

* Node.js
* npm
* Git

### 1. Clone the repository

```bash
git clone https://github.com/panganamalalohi-design/formforge-ai.git
```

### 2. Navigate to the frontend directory

```bash
cd formforge-ai/frontend
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL displayed in your terminal to access the application.

### 5. Create a production build

```bash
npm run build
```

The production files will be generated in the `dist` directory.
